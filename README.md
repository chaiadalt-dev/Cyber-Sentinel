 # 🛡️ Cyber Sentinel - Forensic & Malware Analysis Tool

A forensic-grade security platform designed to perform deep analysis on full system backups, file archives, and mobile systems for malware, spyware, and persistent anomalies.

## 🚀 Overview
Cyber Sentinel features a multi-layered threat detection engine built to identify Advanced Persistent Threats (APTs). The project demonstrates a deep understanding of malware vectors, static analysis, OSINT integration, and secure file handling protocols.

## 🛠️ Key Capabilities & Tech Stack
* **Signature Detection:** Integrated scanning for spyware signatures (e.g., Pegasus, Predator).
* **Malware Engine:** YARA rule integration for precise binary matching.
* **Forensic Analysis:** File entropy calculation and structural anomaly detection.
* **Mobile AppSec:** APK permission mapping and dynamic asset analysis.
* **Language:** Python

## 🔒 Note to Researchers & Recruiters
This tool was developed for ethical security research and forensic learning purposes. It processes files locally and securely. 

## 💻 Quick Start
1. Clone the repository.
2. Install the required forensic dependencies: `pip install -r requirements.txt`
3. Start the analysis engine: `python app.py`
